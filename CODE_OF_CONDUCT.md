# Code of Conduct

BetaNYC supports safe, open, and welcoming collaboration. Participation in this repository requires following [BetaNYC's Code of Conduct and Anti-Harassment Policy](https://www.beta.nyc/code-of-conduct-anti-harassment-policy/).

Report concerns privately to [saferspaces@beta.nyc](mailto:saferspaces@beta.nyc). Do not include personal or sensitive details in a public issue or pull request.
